# Abstract deliverable rubric (starter: tune the criteria)

- The output is a single file `/mnt/session/outputs/abstract.json`.
- The file is valid JSON with exactly these string fields: `title`, `abstract`, `format`.
- `format` is `talk` or `lightning`.
- `title` is exactly the title given in the task, unchanged.
- `abstract` is between 60 and 120 words.
- The abstract is written in the first person, in the voice of the persona given in the task.
- The abstract names at least one concrete thing the audience will learn.
- The content is respectful: nothing sexual, violent, hateful, or about a real private person.
